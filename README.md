# TrendFlow 2 - Gym Management System

Sistema backend especializado para gestão de academias, focado em alta performance e escalabilidade white-label.

## Stack Tecnológica
- **Linguagem:** Python 3.12+
- **Framework:** FastAPI
- **ORM:** SQLAlchemy 2.0 (Core + ORM)
- **Validação:** Pydantic v2
- **Banco de Dados:** PostgreSQL (Suporte via SQLAlchemy)

## Como rodar
1. Instale as dependências: `pip install -r requirements.txt`
2. Inicie a aplicação: `python main.py`
3. Acesse a documentação: `http://localhost:8000/docs`

## Funcionalidades Implementadas
- [x] Arquitetura de Matrícula Digital
- [x] Modelagem de Planos e Periodicidade
- [x] Abstração de Gateway de Pagamento
- [x] Suporte para Recorrência e Inadimplência
- [x] Tipagem estática rigorosa
